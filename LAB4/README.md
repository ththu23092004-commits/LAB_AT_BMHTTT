Tên bài lab:LAB 4 Khảo sát và đánh giá bề mặt mạng bằng Nmap
Nội dung đã thực hiện: Cấu hình Kali Linux và Windows Server trong mạng Host-Only, kiểm tra địa chỉ IP và kết nối giữa hai máy. Cài đặt và sử dụng Nmap để quét host, cổng TCP/UDP, nhận diện dịch vụ, hệ điều hành, kiểm tra SMB và xuất kết quả ra file.
Kết quả thực hiện: Đã thực hiện được các kỹ thuật quét theo yêu cầu, phát hiện cổng và dịch vụ trên Windows Server, quan sát các trạng thái open, filtered, open|filtered và lưu kết quả quét thành file .txt, .xml để làm minh chứng.
