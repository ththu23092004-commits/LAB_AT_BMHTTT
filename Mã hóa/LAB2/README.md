Tên bài lab: LAB 2 – Xây dựng chương trình mã hóa và giải mã bằng các thuật toán mật mã đối xứng hiện đại.
Nội dung đã thực hiện: Xây dựng chương trình bằng Java trên Apache NetBeans, thực hiện mã hóa và giải mã với các thuật toán DES, TripleDES, AES, RC4, Twofish và AES-CTR. Thiết kế giao diện cho từng thuật toán, tích hợp chức năng tạo khóa, IV, nonce, lưu và mở file văn bản. Xây dựng chức năng đăng ký, đăng nhập và tạo Ticket trong bài AES. Kết nối SQL Server để lưu trữ thông tin tài khoản và lịch sử mã hóa, giải mã.
Kết quả thực hiện: Các thuật toán mã hóa và giải mã hoạt động đúng theo kết quả kiểm thử. Chức năng đăng ký, đăng nhập, tạo Ticket và lưu, mở file thực hiện thành công. Chương trình kết nối SQL Server thành công, lưu trữ và hiển thị lịch sử thao tác. Các chương trình Java được biên dịch và chạy thành công trên Apache NetBeans.
