Tên bài lab: LAB 1 – Xây dựng chương trình mã hóa và giải mã bằng các thuật toán mật mã cổ điển.
Nội dung đã thực hiện: Xây dựng chương trình bằng Java trên Apache NetBeans, thực hiện mã hóa và giải mã với 6 thuật toán Caesar, Vigenère, Rail Fence, Playfair, Transposition và Autokey. Xây dựng giao diện tổng hợp, thực hiện các kỹ thuật phân tích mật mã gồm Brute Force Caesar, Frequency Analysis và Known Plaintext Vigenère. Kết nối chương trình với SQL Server để lưu trữ và xem lịch sử mã hóa, giải mã.
Kết quả thực hiện: Các thuật toán mã hóa và giải mã hoạt động theo kết quả kiểm thử. Các chức năng phân tích mật mã thực hiện được, chương trình kết nối SQL Server thành công và lưu, hiển thị lịch sử thao tác đầy đủ. Chương trình chạy thành công trên Apache NetBeans.
