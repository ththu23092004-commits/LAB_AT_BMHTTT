Tên bài lab: LAB 8 – Local DNS Attack trên mô hình pfSense.
Nội dung đã thực hiện: Cấu hình mạng DNSLAB trên VMware và pfSense; thiết lập máy chủ DNS bằng BIND9, mô phỏng máy chủ DNS có thẩm quyền, thực hành chuyển hướng tên miền qua file /etc/hosts và chuẩn bị công cụ thử nghiệm giả mạo phản hồi DNS.
Kết quả thực hiện: Cấu hình thành công mạng DNSLAB, máy chủ DNS và kiểm tra phản hồi DNS hợp lệ. Thực hiện thành công chuyển hướng tên miền bằng file /etc/hosts. Đã chuẩn bị công cụ DNS Spoofing, tuy nhiên phần kiểm thử giả mạo phản hồi và đầu độc bộ nhớ đệm DNS chưa hoàn tất.
